## 回程线路：宣传口径和实测口径不一样

DMIT 给 EB 系列标的线路是：电信回程 AS9929 与 CMIN2 负载均衡，联通回程 AS9929（CUP 精品线路），移动回程 CMIN2（AS58807）。去程方面，电信走 CN2 GIA、联通走 Telia、移动走 CMIN2。这个说法在多份中文评测里被反复引用。

2024 年 4 月一份社区 traceroute 实测给出了另一个画面：北京、上海、深圳三地的电信、联通、移动回程，前五跳全部落在 AS58807（ChinaMobile CMIN2），从上海入境，之后才分别转入 AS9808（移动）、AS4134（电信）、AS4837/AS17623（联通）落地。也就是说，那次测试里三网回程实际是统一走 CMIN2，电信并没有单独走 9929。

两边放在一起看，合理的理解是：官方宣传的是 9929 与 CMIN2 的组合能力，实际走哪条取决于当时的调度，社区实测落在 CMIN2 上。这也解释了为什么移动和联通用户对这台机器的评价普遍接近 Pro 系列，而电信用户会觉得"不差，但差点意思"。

延迟方面，同一份 2024 年 4 月的测试里，联通各城市 136 到 187 ms，电信 136 到 191 ms，移动 133 到 154 ms。北京电信 153.73 ms、上海电信 128.96 ms、深圳电信 154.06 ms，北京移动 153.99 ms、上海移动 129.99 ms。这是两年多前的数据，只能当参考基准，别当成今天晚高峰的承诺。

还有一条第三方说法：有评测称 DMIT 与国内三大运营商直签合同，持有 CN2 GIA 40 Gbps、9929 20 Gbps、CMIN2 20 Gbps 的带宽资源，搬瓦工的部分线路用的是 DMIT 上游。这些在官网上找不到对应说明，当背景信息看就行，不用当成购买依据。

## 1 GB 内存够不够，看你要跑什么

静态站、Nginx 反代、Go 或 Rust 编译出来的单文件服务、轻量代理，1 GB 完全够，甚至有余量。这类程序的常驻内存通常在一两百 MB 级别。

会紧张的是这几种组合：Docker 里同时跑三四个容器；MySQL 或 PostgreSQL 加一个 Web 应用；宝塔面板再叠一个 WordPress。系统本身要吃掉一百多 MB，剩下的空间经不起这么多进程抢。真要在 1 GB 上跑数据库，Swap 会频繁介入，磁盘 IO 跟着遭殃。

一句话判断：如果你打算装 MySQL + Docker + 面板建站，别买 WEE，去看 FONTANA 的 2 GB。如果你只是放几个静态页面、跑个 API、做落地节点，WEE 的 CPU 和磁盘不是瓶颈，内存也不是。

## FAQ

**WEE 和 CORONA 差在哪？**

同一年付周期，价格差 $10。CORONA 的流量和带宽都比 WEE 高一档，CPU、内存、硬盘容量相同。月流量稳定超过 1 TB 就选 CORONA，用不到就省这 $10。

**流量用完了机器会关掉吗？**

不会。限速到 2 Mbps 继续运行，SSH 和基础 Web 服务照常，下个月流量重置后恢复原速。

**电信用户能用吗？**

能。2024 年的实测里电信延迟 136 到 191 ms，和联通移动在一个区间。只是回程实际落在 CMIN2 而不是 9929 或纯 GIA，对延迟极度敏感的场景还是看 Pro。

**Netflix 和 Disney+ 能解锁吗？**

Netflix 只能看原创内容（Originals Only），区域标为美国区。YouTube 正常，TikTok 解锁美国区，ChatGPT 可访问。Disney+ 的记录互相矛盾，有的测试说不可用，有的脚本输出前后不一致，别把它当购买理由。

**AN4 和 AN5 有什么区别？**

AN4 是 AMD EPYC 9654，AN5 是更新的 EPYC 9005 系列。WEE、CORONA、FONTANA 这三个特价年付款在 AN4 上，常规月付的 TINY、STARTER 等在 AN5 上。日常建站和轻量服务，9654 不是瓶颈。

**付款后多久能开通？**

一般几分钟内系统自动部署，开通信息发到邮箱。极少出现长时间等待。
